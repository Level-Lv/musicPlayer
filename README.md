## 🚀 核心功能展示

### 1️⃣ 支持桌面窗口歌词显示
* **桌面歌词**：默认位于桌面顶层居中的无边框悬浮窗口，允许用户自行拖动。

> ![](https://github.com/user-attachments/assets/283fa099-8c2a-499f-bced-f5576bf8715f)

---

### 2️⃣ 支持自定义背景
* **背景视频**：通过右上角按键选择视频文件可导入背景中，视频会在界面静音循环播放。
* **唱片旋转**：点击圆，选择一张图片即可，选择后会一直循环转动。

### 3️⃣ 模糊搜索
* **高亮显示**：通过正上方的搜索框输入进行搜索后，对应部分的文字会高亮
* **回车轮转结果**：对于多个结果的搜索，按下回车能快速定位到下一个搜索结果处，可循环。

## 温馨提示

* **运行环境要求**：
    * 本项目基于 **.NET 8.0** 开发，运行前请确保本地已安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)。
* **歌词方面**：
    * 需要自行导入.lrc文件，导入位置在exe程序同级目录下的"lrc"文件夹中，请勿将.lrc文件放至别处。
    * .lrc文件名需与对应的.mp3文件名相同，例如**反方向的钟.mp3**文件，其歌词对应**反方向的钟.lrc**文件，请注意命名。
